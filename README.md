# ใบปะหน้าขนส่ง — บริษัท เมืองเกษตร จำกัด

เว็บทำใบปะหน้าขนส่งและใบยืนยันส่งมอบ จากไฟล์ออเดอร์ CSV
ทำงานในเบราว์เซอร์ล้วนๆ ไม่มีเซิร์ฟเวอร์ ไฟล์ที่อัปโหลดไม่ถูกส่งออกไปไหน

## วิธีเอาขึ้น GitHub Pages

1. เข้า github.com กด **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ เช่น `mks-labels` · เลือก **Private** (แนะนำ เพราะในไฟล์มีตารางสินค้าและจำนวนบรรจุหีบ) · กด **Create repository**
3. ในหน้า repo กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป (ลากทั้งโฟลเดอร์ `data` ไปด้วย) → กด **Commit changes**
4. ไปที่ **Settings** → **Pages** → ตรง *Branch* เลือก `main` / `/ (root)` → **Save**
5. รอ 1–2 นาที แล้วรีเฟรชหน้า Pages จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/mks-labels/`

> Private repo จะเปิด Pages ได้เฉพาะบัญชีแบบ Pro/Team ขึ้นไป
> ถ้าใช้บัญชีฟรีแล้วอยากได้ลิงก์ ต้องตั้ง repo เป็น Public
> หรือเปิดไฟล์ `index.html` จากเครื่องตรงๆ ก็ใช้งานได้เหมือนกัน ไม่ต้องมีเน็ต

## เวลาแก้ของในเว็บ

- **เพิ่ม/แก้ชื่อขนส่ง** → `data/aliases.js` (คู่ของ `["คำที่ค้นหา", "ชื่อที่จะพิมพ์"]`)
- **แก้จำนวนบรรจุหีบของสินค้า** → `data/products.js` ช่อง `p` ของรหัสนั้น
- **แก้ชื่อผู้ส่ง / เบอร์** → `app.js` ค้นคำว่า `ก้อย (MKS)`

แก้ไฟล์บน GitHub ได้โดยตรง กดที่ไฟล์ → ไอคอนดินสอ → Commit changes แล้วเว็บจะอัปเดตเองใน 1–2 นาที

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บและสไตล์ทั้งหมด (รวมสไตล์ตอนพิมพ์) |
| `app.js` | การทำงานของหน้าจอ ปุ่ม ตาราง ใบยืนยัน และไฟล์ Word |
| `core.js` | อ่าน CSV, จัดชื่อขนส่ง/ที่อยู่, คำนวณจำนวนลัง |
| `data/products.js` | ตารางสินค้า 551 รหัส พร้อมจำนวนบรรจุหีบ |
| `data/aliases.js` | ตารางแปลงชื่อขนส่งให้เป็นชื่อมาตรฐาน |
| `test/run.js` | ทดสอบด้วย node: `node test/run.js ไฟล์.csv` |

## การคำนวณจำนวนลัง

จับคู่ด้วย **รหัสสินค้า** (เช่น `CHAR0004`) ไม่ใช่ชื่อ เพราะชื่อสินค้าซ้ำกันได้ในต่างแบรนด์
จำนวนลัง = จำนวนที่สั่ง ÷ บรรจุต่อหีบ ปัดขึ้น · ของแถม (รหัส `FOC`) ไม่นับ · รหัสที่ไม่มีในตารางจะขึ้นเตือนสีส้ม
